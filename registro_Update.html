TRAE IDIdentidad y seguridad estudiantil
Sistema RUTAESTE

Un carnet digital pensado para la seguridad del estudiante.

Registro, identificación mediante QR, contacto de emergencia y control administrativo en una sola plataforma. Este prototipo demuestra la experiencia de usuario antes de conectarlo a un backend real.

Cómo funciona

Flujo propuesto

Estudiante

Se registra, agrega su foto y recibe un carnet con un código QR único.

Padre / tutor

Autoriza datos y mantiene actualizados los contactos de emergencia.

Conductor / inspector

Escanea el QR y consulta la identidad y los datos permitidos.

Protección de datos

En una versión real, el QR debería contener solamente un identificador o token y no los datos personales completos. El servidor decide qué información puede ver cada rol.
